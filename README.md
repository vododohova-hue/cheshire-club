# Cheshire Club

8-битная браузерная игра по мотивам «Алисы в Стране Чудес» для дискуссионно-психологического клуба «Чеширский кот».

**Играть:** https://vododohova-hue.github.io/cheshire-club/

Улыбка Чеширского кота разбилась на 5 кусочков и разлетелась по залам клуба. Собери их все и вернись к круглому столу. Чем быстрее, тем выше место в рейтинге.

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Идти | ← → | стрелки на экране |
| Прыжок | пробел или ↑ | кнопка «Прыжок» |
| Ироничная реплика | X | кнопка X |
| Мурчание | Z | кнопка Z |
| Мудрый взгляд | C | кнопка C |
| Исчезнуть | V (держать) | кнопка V |
| Звук | M | кнопка «Звук» |
| Подтвердить | Enter | «ОК» или касание экрана |

На телефоне удобнее играть горизонтально. На титульном экране: **H** — «Как играть», **L** — таблица рекордов.

## Пять залов

1. **Бар** — угости 5 гостей: каждому нужна 1 чашка кофе и 1 конфета. Врагов-проблем сначала замораживай репликой (X), потом добивай прыжком сверху. Враг отнимает конфету, шипы проливают кофе. Упал в яму — уровень сначала.
2. **Вторник, тренинги** — 4 станции навыков. Появляется двойной прыжок.
3. **Среда, отдых** — расслабь 6 напряжённых гостей мурчанием (Z).
4. **Четверг, бизнес-мастермайнд** — собери шестерёнки строго по порядку: идея, структура, маркетинг, масштаб.
5. **Пятница, отношения** — мудрый взгляд (C), 3 причины, 4 зеркала, 2 разговора.

В конце каждого зала — босс.

## Советы

- Подобранный зуб лечит улыбку.
- Не жми X в бою с Двойником: сарказм — это защита.
- Секундомер идёт всю игру: падения и ошибки — это время.
- После финала впиши имя в таблицу рекордов. Результат хранится в браузере; чтобы сравниться с друзьями, отправь им код результата (клавиша C на экране рекордов), а их коды добавляй клавишей I.

## Для разработчиков

Вся игра — один файл `index.html` (HTML5 Canvas и vanilla JS, графика и звук нарисованы в коде, интернет не нужен). Сценарий — в `scenario.md`, рабочие правила проекта — в `CLAUDE.md`.
